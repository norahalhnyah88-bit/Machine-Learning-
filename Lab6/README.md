## Lab 6: Linear Regression

This lab applies Linear Regression to the Ecommerce Customers dataset to predict the yearly amount spent by customers.
### Dataset
- File: `Ecommerce Customers.csv`
- Target Variable: `Yearly Amount Spent`
- Problem Type: Regression
- ### Techniques Used
- Data exploration
- Data visualization
- Train-test split
- Linear Regression
- Model prediction
- Model evaluation using MAE, MSE, RMSE, and R²
